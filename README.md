# 📝 Google Docs Quick Prepender
**〜思いついた瞬間に、ドキュメントの先頭へメモを放り込むツール〜**

このツールは、指定したGoogleドキュメントの**一番上の行**に、日時（JST）付きでテキストを追記するためのGoogle Apps Script（GAS）ウェブアプリケーションです。
ブラウザからサクッと入力して、ドキュメントを開く手間なく情報を蓄積できます。

---

## ✨ 主な機能
* **ドキュメント選択の柔軟性**：
    * 起動時は「最近使用した5件」を素早く表示します。
    * 「すべてのドキュメントを表示」ボタンで全件取得ができ、名前順（日本語対応）でソートされます。
* **スマートな追記（Prepending）**：
    * ドキュメントの末尾ではなく、**先頭（0番目の位置）**に挿入されます。
    * 最新のメモが常に一番上に来るため、スクロール不要で確認が容易です。
* **自動タイムスタンプ**：
    * 日本時間（JST）で「【yyyy/MM/dd HH:mm】」という形式のヘッダーが自動で付与されます。
* **快適なUI/UX**：
    * 目に優しいダークモードを採用。
    * スマートフォンからの入力を考慮したレスポンシブ設計（viewport設定済み）。
    * 保存中はボタンが無効化され、二重送信やエラーを防止します。

---

## 🤖 AIツールとの最強連携
このツールでGoogleドキュメントに情報を集約することで、最新のAIを最大限に活用できます。

* **NotebookLM で活用**
    * Google ドキュメントをソースとして登録すれば、ドキュメントを更新した後に NotebookLM 側で**「更新（再取得）」ボタンを1クリック**するだけで、最新のメモに基づいた回答が得られます。
* **Gemini で活用**
    * Google Workspace 拡張機能を利用して、Gemini から直接ドキュメントを読み込めます。アップロードの手間なく、常に最新情報に基づいた分析や要約が可能です。

## 🚀 セットアップ方法

1.  **Google Apps Scriptプロジェクトの作成**
    * [Google Apps Script](https://script.google.com/)で新しいプロジェクトを作成します。
2.  **ファイルの配置（3つのファイルを貼り付けます）**

    | GitHubのファイル | Apps Script側の場所 | 貼り方 |
    |---|---|---|
    | `音声入力用スクリプト.gs` | 「コード.gs」 | 中身を全部消して、内容を貼り付け |
    | `index.html` | 「＋」→「HTML」で作成 | ファイル名を `index` にして、内容を貼り付け |
    | `appsscript.json` | 「appsscript.json」 | 下の手順で表示してから、内容を貼り付け |

    * **① .gs を貼る**：エディタ左のファイル一覧で「コード.gs」を開き、中身を全部消して `音声入力用スクリプト.gs` の内容を貼り付けます。
    * **② html を貼る**：ファイル一覧の「＋」→「HTML」を選び、名前を `index`（拡張子不要）にします。できたファイルの中身を全部消して `index.html` の内容を貼り付けます。
    * **③ json を貼る**：左の歯車「プロジェクトの設定」→「「appsscript.json」マニフェスト ファイルをエディタで表示する」にチェックを入れます。エディタに戻ると `appsscript.json` が増えているので、中身を全部消して `appsscript.json` の内容を貼り付けます。
    * 最後に 💾 で保存します。
3.  **デプロイ**
    * 初回：「デプロイ」→「新しいデプロイ」→ 種類を「ウェブアプリ」に設定します。
    * **設定**：
        * 次のユーザーとして実行：自分
        * アクセスできるユーザー：自分のみ（推奨）
    * 2回目以降（コードを変更したとき）：「デプロイ」→「デプロイを管理」→ ✏️ 編集 → バージョンを「新バージョン」にして「デプロイ」。URLが変わりません。
4.  **承認**
    * デプロイ後に発行されたURLにアクセスし、Googleドキュメントへのアクセス権限を承認します。
5.  **ドキュメントの登録**
    * 画面の「➕ ドキュメントを登録する」を開き、追記したいGoogleドキュメントのURLを貼って「登録」を押します。
    * 高度な保護機能プログラムを使っていても動くよう、Drive全体へのアクセスは使わず、登録方式にしています。

## 🛠 使い方
1.  ウェブアプリのURLを開きます。
　[Google Apps Script](https://script.google.com/)で「デプロイ」→「デプロイを管理」→ＵＲＬ（https://script.google.com/macros/…）をクリック
2.  **「📂 追記先のドキュメント」**から対象のファイルを選択します。
3.  **「📝 入力内容」**にメモしたいテキストを入力します。
4.  **「📄 文書の先頭に保存」**をクリックすると、即座にドキュメントへ反映されます。

## 📝 技術仕様
* **言語**: Google Apps Script (JavaScript), HTML5, CSS3
* **使用API**: 
    * `PropertiesService`: 登録したドキュメント一覧の保存。
    * `DocumentApp`: 指定IDのドキュメントオープンおよび段落（0番目）への挿入。
* **タイムゾーン**: `JST` (日本標準時)
* **エラーハンドリング**: ファイル未選択や空入力時のアラート、GAS側でのtry-catch処理を実装済み。
