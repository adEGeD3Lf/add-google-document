# 📝 Google Docs Quick Prepender
**〜思いついた瞬間に、ドキュメントの先頭へメモを放り込むツール〜**

このツールは、指定したGoogleドキュメントの**一番上の行**に、日時（JST）付きでテキストを追記するためのGoogle Apps Script（GAS）ウェブアプリケーションです。
ブラウザからサクッと入力して、ドキュメントを開く手間なく情報を蓄積できます。

---

## ✨ 主な機能
* **ドキュメント選択の柔軟性**：
    * 起動時は「最近使用した5件」を素早く表示します。
    * 「すべてのドキュメントを表示」ボタンで全件取得ができ、名前順（日本語対応）でソートされます。
* **スマートな追記（Prepending）**：
    * ドキュメントの末尾ではなく、**先頭（0番目の位置）**に挿入されます。
    * 最新のメモが常に一番上に来るため、スクロール不要で確認が容易です。
* **自動タイムスタンプ**：
    * 日本時間（JST）で「【yyyy/MM/dd HH:mm】」という形式のヘッダーが自動で付与されます。
* **快適なUI/UX**：
    * 目に優しいダークモードを採用。
    * スマートフォンからの入力を考慮したレスポンシブ設計（viewport設定済み）。
    * 保存中はボタンが無効化され、二重送信やエラーを防止します。

---

## 🤖 AIツールとの最強連携
このツールでGoogleドキュメントに情報を集約することで、最新のAIを最大限に活用できます。

* **NotebookLM で活用**
    * Google ドキュメントをソースとして登録すれば、ドキュメントを更新した後に NotebookLM 側で**「更新（再取得）」ボタンを1クリック**するだけで、最新のメモに基づいた回答が得られます。
* **Gemini で活用**
    * Google Workspace 拡張機能を利用して、Gemini から直接ドキュメントを読み込めます。アップロードの手間なく、常に最新情報に基づいた分析や要約が可能です。

## 🚀 セットアップ方法

> 💡 所要時間は10〜15分ほどです。プログラミングの知識は要りません。「コピーして貼る」ができれば大丈夫です。
> 必要なもの：**Googleアカウント**（普段使っているものでOK）とパソコンのブラウザ（Chrome推奨）

### ステップ0：このGitHubから、3つのファイルの中身を用意する
このページの上の方にあるファイル一覧に、次の3つがあります。それぞれ「中身をコピー」できる状態にしておきます。

* `音声入力用スクリプト.gs`
* `index.html`
* `appsscript.json`

コピー方法：ファイル名をクリックして開き、右上の **コピーボタン（四角が2つ重なったアイコン📋）** を押すと、中身が全部コピーされます。
（貼り付けるたびにここへ戻って、次のファイルをコピーします。）

### ステップ1：新しいプロジェクトを作る
1. ブラウザで [https://script.google.com/](https://script.google.com/) を開きます。
2. Googleアカウントでログインしていなければ、ログインします。
3. 画面左上の **「＋ 新しいプロジェクト」** ボタンを押します。
4. 「無題のプロジェクト」というエディタ画面が開きます。
5. 画面上部の **「無題のプロジェクト」** をクリックして、分かりやすい名前（例：`ドキュメント簡単入力`）に変えて「OK」を押します。

### ステップ2：3つのファイルを貼り付ける
画面の左側に、ファイル一覧（最初は **「コード.gs」** だけ）が出ています。

**① .gs を貼る**
1. 左の一覧で **「コード.gs」** をクリックして開きます。
2. 真ん中の入力欄に最初から書いてある文字（`function myFunction() {` など）を、`Ctrl + A`（全選択）→ `Delete` で **全部消します**。
3. GitHubでコピーしておいた `音声入力用スクリプト.gs` の中身を、`Ctrl + V` で貼り付けます。

**② html を貼る**
1. 左の「ファイル」の横にある **「＋」** を押し、**「HTML」** を選びます。
2. 名前の入力欄が出るので、**`index`** と入力して Enter を押します（「.html」は自動で付くので書きません）。
3. 作られた `index.html` を開き、最初から書いてある文字を `Ctrl + A` → `Delete` で全部消します。
4. GitHubからコピーした `index.html` の中身を貼り付けます。

**③ json を貼る**
1. 左のメニューの **歯車アイコン「プロジェクトの設定」** を押します。
2. **「「appsscript.json」マニフェスト ファイルをエディタで表示する」** にチェックを入れます。
3. 左のメニューの **「<> エディタ」** に戻ると、ファイル一覧に `appsscript.json` が増えています。それを開きます。
4. 書いてある文字を `Ctrl + A` → `Delete` で全部消します。
5. GitHubからコピーした `appsscript.json` の中身を貼り付けます。

**④ 保存する**
* 3つとも貼れたら、各ファイルで `Ctrl + S`（または上の💾アイコン）を押して保存します。

### ステップ3：公開（デプロイ）する
1. 画面右上の青い **「デプロイ」** ボタン →  **「新しいデプロイ」** を押します。
2. 出てきた画面の **「種類の選択」の横の歯車アイコン⚙** を押して、 **「ウェブアプリ」** を選びます。
3. 次のように設定します。
    * 説明：空欄でもOK（例：`初回`）
    * **次のユーザーとして実行：自分**
    * **アクセスできるユーザー：自分のみ**（他人に使われないので安全です）
4. **「デプロイ」** ボタンを押します。

### ステップ4：権限を許可する（初回のみ）
1. 「アクセスを承認」というボタンが出たら押します。
2. Googleアカウントを選びます。
3. 「Googleドキュメントの表示、編集…」というアクセス許可の画面が出るので、内容を確認して **「許可」** を押します。
    * 「このアプリは Google で確認されていません」と出ることがあります。自分で作ったプログラムなので、左下の **「詳細」→「（プロジェクト名）に移動（安全ではないページ）」** を押して進めて大丈夫です。
    * 「高度な保護機能プログラム」を使っている場合は、このプログラムが「ブロックされました」と出ることがあります。その場合は下の「困ったとき」を見てください。

### ステップ5：ウェブアプリのURLをコピーして開く
1. 「デプロイを更新しました」という画面に **「ウェブアプリ」のURL**（`https://script.google.com/macros/s/…/exec`）が出ます。
2. URLの右にある **「コピー」** を押します。
3. 新しいタブに貼り付けて開くと、このツールの画面が出ます。
4. **ブックマークしておく** と、次からすぐ開けて便利です。スマホなら、ブラウザのメニューから「ホーム画面に追加」しておくと、アプリのように使えます。

### ステップ6：追記したいGoogleドキュメントを登録する
1. 画面の **「➕ ドキュメントを登録する」** をクリックして開きます。
2. 別のタブで、メモを書き込みたいGoogleドキュメントを開きます。
3. ブラウザ上部の **アドレスバーのURL**（`https://docs.google.com/document/d/…`）を全部コピーします。
4. このツールの入力欄に貼り付けて **「登録」** を押します。
5. 「✅ 登録しました」と出れば完了です。「追記先のドキュメント」の選択肢に出てきます。
    * 登録は何個でもできます。
    * 高度な保護機能プログラムを使っていても動くよう、Drive全体へのアクセスは使わず、この登録方式にしています。

### 🔄 あとからプログラムを変更したとき（2回目以降）
貼り付けた内容を修正したら、**「デプロイ」→「デプロイを管理」→ ✏️（編集）→ バージョンを「新バージョン」にして「デプロイ」** を押します。これでURLが変わらずに更新できます。
（「新しいデプロイ」を選ぶとURLが変わってしまうので、普通は使いません。）

### 🆘 困ったとき
* **URLが分からなくなった**：[script.google.com](https://script.google.com/) でプロジェクトを開き、「デプロイ」→「デプロイを管理」で確認できます。
* **「ブロックされました」と出る**：高度な保護機能プログラムが原因の可能性があります。ステップ6の登録方式（このREADMEの版）になっているか確認してください。それでも出る場合は、[g.co/advancedprotection](https://g.co/advancedprotection) から一時的にオフにして試せます。
* **「保存に失敗しました」と出る**：登録したドキュメントが削除された、またはアクセス権がない可能性があります。ドキュメントを登録し直してください。

## 🛠 使い方
1.  ウェブアプリのURLを開きます。
　[Google Apps Script](https://script.google.com/)で「デプロイ」→「デプロイを管理」→ＵＲＬ（https://script.google.com/macros/…）をクリック
2.  **「📂 追記先のドキュメント」**から対象のファイルを選択します。
3.  **「📝 入力内容」**にメモしたいテキストを入力します。
4.  **「📄 文書の先頭に保存」**をクリックすると、即座にドキュメントへ反映されます。

## 📝 技術仕様
* **言語**: Google Apps Script (JavaScript), HTML5, CSS3
* **使用API**: 
    * `PropertiesService`: 登録したドキュメント一覧の保存。
    * `DocumentApp`: 指定IDのドキュメントオープンおよび段落（0番目）への挿入。
* **タイムゾーン**: `JST` (日本標準時)
* **エラーハンドリング**: ファイル未選択や空入力時のアラート、GAS側でのtry-catch処理を実装済み。
